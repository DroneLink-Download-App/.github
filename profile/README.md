## Tips Before Your First Mission

→ Review the complete route, altitude settings, and mission actions before connecting the aircraft.
→ Verify equipment compatibility, permissions, battery readiness, and local operating conditions before takeoff.
→ Start with a simple mission so you can become familiar with the DroneLink app interface and dashboard feedback.
